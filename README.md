A steady incompressible flow through a circular pipe is simulated using ANSYS Fluent.
The objective is to automate:

1. Mesh generation
2. Solver setup
3. Boundary-condition assignment
4. Solution initialization
5. Solver execution
6. Pressure-drop calculation
7. Mesh-convergence analysis
8. CSV/plot generation

The geomtery, material properties and mesh type are as follows:-
| Parameter         |      Value |
| ----------------- | ---------: |
| Pipe diameter     |      25 mm |
| Pipe length       |        1 m |
| Inlet velocity    |    0.5 m/s |
| Pressure outlet   |      1 bar |
| Density           |  847 kg/m³ |
| Dynamic viscosity |  0.02 Pa·s |
| Mesh              | Polyhedral |
